## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-01 | Information Disclosure | messenger-bot/src/index.ts → sendTypingIndicator error handler | mitigate | Apply SEC-03 pattern exactly: `if (axios.isAxiosError(err)) { console.error("sendTypingIndicator failed:", err.message, err.response?.data); } else { console.error("sendTypingIndicator failed (unexpected error):", err); }`. Never log the bare `err` value or `err.config`, because `err.config.url` contains the full POST URL with `?access_token=<PAGE_ACCESS_TOKEN>` query parameter. Acceptance criteria for Task 1 includes a negative grep proving no bare-err logging exists in sendTypingIndicator. |
| T-5-02 | Tampering | sendTypingIndicator request body | accept | `recipientId` is the customer's PSID supplied by Facebook on the inbound webhook (already authenticated via HMAC in verifySignature). `action` is a TypeScript-narrowed literal union (`"typing_on" | "typing_off"`) — the compiler rejects any other value. No user-supplied free text reaches the Graph API body. No additional validation needed. |
| T-5-03 | Denial of Service (self-inflicted) | sendAnswer typing_off in finally block | mitigate | If sendTypingIndicator(typing_off) throws AFTER sendMessage already resolved, the error is swallowed by sendTypingIndicator's own try/catch. The customer has already received the answer. The finally block cannot mask a delivery failure because typing_off runs strictly after the sendMessage await resolves or the catch block runs. |
| T-5-04 | Information Disclosure (docs) | messenger-bot/.env.example | mitigate | The file contains only placeholder strings (`your_*_here`) and the canonical PAGE_INBOX_APP_ID public constant (`263902037430900` — published in Facebook docs). No secret material is checked in. The commented `# PAGE_INBOX_APP_ID=...` line uses the `#` prefix so dotenv does not load it as an env var (defense in depth — even if a developer fills the surrounding blanks, this line stays inert until they explicitly uncomment). |
</threat_model>
