## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client browser -> FastAPI Q&A API | Authenticated tenant (JWT) mutates their own page's Q&A |
| `page_id` / `item_id` path params -> DB | Caller-supplied ids select which rows are read/mutated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-08 | Elevation of privilege / Tampering | Cross-tenant Q&A list/mutate | mitigate | `_require_owned_page` (`pages WHERE id = ? AND tenant_id = ?`) on every endpoint; 404 on foreign page. Tested by `test_qa_cross_tenant_404` |
| T-13-09 | Tampering / Referential integrity | `category_id` pointing at a non-category or another page's row | mitigate | `_validate_category_ref` (`qa_items WHERE id = ? AND page_id = ? AND type = 'category'`) on POST/PUT -> 400; self-reference rejected. Tested by `test_qa_post_invalid_category_ref_400`, `test_qa_category_ref_other_page_rejected_400` |
| T-13-10 | Tampering | PUT/DELETE on an item_id belonging to a different page | mitigate | item-belongs-to-page check `qa_items WHERE id = ? AND page_id = ?` before mutation -> 404. Tested by `test_qa_item_page_mismatch_404` |
| T-13-11 | Spoofing | Unauthenticated Q&A write | mitigate | `Depends(get_current_tenant)` required. Tested by `test_qa_unauthenticated_401` |
| T-13-12 | Tampering | SQL construction | mitigate | `?`-placeholders only; grep gate asserts no f-string SQL |
| T-13-SC | Tampering (supply chain) | pip installs | accept | No new packages this phase; no new supply-chain surface |
