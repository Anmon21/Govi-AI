<objective>
Replace the vault-backed content router with DB-backed read endpoints that serve
per-page Q&A from `qa_items`, guarded by the `X-Internal-Key` HMAC pattern (D-01),
while preserving the exact `/content` HTTP contract the bot depends on. Fully retire the
Obsidian vault everywhere it is referenced at runtime: `content.py` (`_vault`,
`load_vault`, `POST /content/reload`), `main.py` (lifespan wiring), and `health.py`
(the `vault_loaded` / `content_count` fields that read `content._vault`). Clean up the
now-orphaned vault test fixtures in `conftest.py`.

Purpose: Content served from the database per Page ID is the serving half of
CONTENT-03 ("the bot serves the updated Q&A tree without a restart") and the
foundation Phase 14 rewires the bot onto. Retiring the vault must be complete — a
partial retirement leaves `GET /health` raising `AttributeError` at runtime.
Output: DB-backed `content.py`, cleaned `main.py` + `health.py`, rewritten
`test_content.py` + `test_health.py`, de-orphaned `conftest.py`.
</objective>
