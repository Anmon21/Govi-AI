      `payload: str`. `extra="forbid"` implements D-04's "smallest contract to validate"
      (reject unknown keys / nested shapes).
    - `PageConfigRequest(BaseModel)`: `welcome_text: str`, `menu_json: list[MenuItem]`,
      `escalation_psid: Optional[str] = None`, `escalation_message: Optional[str] = None`.
      A flat list of `MenuItem` enforces the D-04 flat-array schema; a nested or malformed
      menu fails Pydantic validation -> 422 automatically.
    - `PageConfigResponse(BaseModel)`: `page_id: int`, `welcome_text: str`,
      `menu_json: list[MenuItem]`, `escalation_psid: Optional[str]`,
      `escalation_message: Optional[str]`, `updated_at: str`.

    Add `@router.put("/pages/{page_id}/config", response_model=PageConfigResponse)`
    `async def put_page_config(page_id: int, request: PageConfigRequest,
    current: dict = Depends(get_current_tenant))`. `page_id` is the internal `pages.id`
    (document this in the docstring, contrasting it with the read API's page_fb_id).

    Body:
    1. `tenant_id = int(current["sub"])`; open `get_connection(settings.db_path)`.
    2. Ownership check first: `SELECT id FROM pages WHERE id = ? AND tenant_id = ? AND is_active = 1`;
       404 "Page not found" if absent (never leak another tenant's page).
    3. Serialize the menu: `menu_str = json.dumps([m.model_dump() for m in request.menu_json])`.
    4. Whole-row replace keyed on the UNIQUE `page_configs.page_id`:
       `SELECT id FROM page_configs WHERE page_id = ?`; if present, `UPDATE page_configs
       SET welcome_text = ?, menu_json = ?, escalation_psid = ?, escalation_message = ?,
       updated_at = strftime(...) WHERE page_id = ?`; else `INSERT INTO page_configs
       (page_id, welcome_text, menu_json, escalation_psid, escalation_message) VALUES (?,?,?,?,?)`.
       Set `updated_at` on update to the same `strftime('%Y-%m-%dT%H:%M:%SZ','now')` idiom
       used in the schema defaults.
    5. `conn.commit()`, then re-`SELECT welcome_text, menu_json, escalation_psid,
       escalation_message, updated_at FROM page_configs WHERE page_id = ?`.
    6. Build `PageConfigResponse`, parsing the stored `menu_json` back with
       `json.loads(row["menu_json"])`. `conn.close()` in `finally`.

    `?`-placeholders only. No try/except around DB calls — raise `HTTPException` directly.
    Add `import json` if not present.
