<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.env` -> Settings | Untrusted-by-default values (JWT_SECRET, SUPER_ADMIN_PASSWORD) cross into application memory; must never be logged |
| Settings -> JWT signing | `jwt_secret` becomes signing key for all access tokens; compromise = full impersonation |
| Plaintext password -> bcrypt hash | Plaintext SUPER_ADMIN_PASSWORD is held in memory only during seed; hash is what persists |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information Disclosure | `app/auth.py:create_access_token` | mitigate | RuntimeError guard if `settings.jwt_secret == ""`; mirrors `app/crypto.py:_fernet`. Prevents accidentally signing tokens with empty/default key |
| T-11-02 | Spoofing | `app/auth.py:verify_token` | mitigate | `algorithms=["HS256"]` passed as a list — rejects `alg:none` and algorithm-confusion attacks (RESEARCH.md Pitfall 1 + Security Domain table) |
