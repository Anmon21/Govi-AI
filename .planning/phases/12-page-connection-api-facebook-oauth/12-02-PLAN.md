## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → API (/pages, /pages/{id}, /pages/{id}/health) | Authenticated client JWT crosses; server must verify Bearer token and enforce tenant_id scope on every query |
| API → SQLite (pages table) | Tenant-scoped queries only; row ownership verified on every read/write that targets a specific page id |
| API → Facebook Graph (debug_token, unsubscribed_apps) | Outbound; uses app_token (app_id|app_secret) for debug_token and Page token for unsubscribe. App secret never returned in response bodies. |
