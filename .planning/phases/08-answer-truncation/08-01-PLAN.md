Purpose: Long vault answers overwhelm the Messenger chat thread on mobile. Phase 8 keeps the preview readable and lets users opt into the full text (UX-04, UX-05).

- New `READ_MORE:` dispatch case in `handleWebhookEvent`

| Bot → Facebook Graph API | Outbound POSTs include `PAGE_ACCESS_TOKEN`. Existing concern — Phase 8 introduces no new exposure here. |
